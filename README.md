# 霓虹幸存者 Neon Survivors

霓虹几何风格的类幸存者（Vampire Survivors-like）网页游戏。Phaser 3 + TypeScript + Vite。

**在线游玩：https://wt19980620-maker.github.io/neon-survivors/** （电脑和手机浏览器都可以）

推送到 `main` 后 GitHub Actions 会自动构建并部署（`.github/workflows/deploy.yml`）。

## 运行

```bash
npm install
npm run dev      # 开发服务器 http://localhost:5173
npm run build    # 生产构建到 dist/（纯静态文件，可直接部署）
```

## 玩法

- WASD / 方向键移动，触屏拖动虚拟摇杆；武器自动攻击
- Esc / P 暂停，M 静音；主菜单和暂停界面可单独开关音乐
- 捡经验宝石升级，每次三选一；最多 4 把武器、5 个被动
- 5:00 首领「猩红守望者」，10:00 最终首领「虚空之主」，击败即胜利
- 精英怪和首领掉落宝箱（额外一次升级）
- 每局结束获得金币，可在菜单「局外强化」永久提升

### 武器与进化

武器满级 + 持有对应被动，打开宝箱时进化（暂停界面可查看配方进度）。

| 武器 | 被动 | 进化 |
|---|---|---|
| 能量飞弹 | 急速 | 风暴弹幕：追踪连射 |
| 环绕刃 | 领域 | 星环绞杀：8 刃，半径胀缩 |
| 脉冲新星 | 活力 | 生命脉冲：命中回血 |
| 连锁闪电 | 力量 | 雷霆审判：终点雷暴爆炸 |
| 回旋飞盘 | 多重 | 裂变星盘：远端裂变 3 个小飞盘 |
| 光束 | 疾行 | 湮灭光束：光束持续绕身旋转 |
| 冰霜领域 | 护甲 | 绝对零度：周期性冻结范围内敌人 |
| 地雷 | 磁力 | 磁暴雷阵：吸引敌人，连锁引爆 |

### 敌人

追踪者、蝙蝠（成群、转向慢）、重甲兵、喷吐者（远程，保持距离射击）、分裂者（死亡分裂 3 只小怪）、
自爆虫（靠近后引信 0.55 秒爆炸，也会炸伤其他敌人），以及每 75 秒一只的金色精英怪。

### 角色与成就

5 个角色，初始武器和属性各不相同，通过成就解锁；13 个成就，完成即得金币。

| 角色 | 初始武器 | 特点 | 解锁 |
|---|---|---|---|
| 霓光行者 | 能量飞弹 | 均衡 | 默认 |
| 重甲守卫 | 环绕刃 | 生命 +50%，护甲 +2，移速 -10% | 击败猩红守望者 |
| 疾风刺客 | 回旋飞盘 | 移速 +20%，伤害 +15%，生命 -30% | 单局击杀 1500 |
| 雷鸣术士 | 连锁闪电 | 冷却 -15%，范围 +10%，生命 -10% | 进化任意武器 |
| 脉冲修士 | 脉冲新星 | 回复 +1/秒，拾取 +50%，伤害 -10% | 单局达到 25 级 |

## 代码结构

| 文件 | 内容 |
|---|---|
| `src/game/data.ts` | 所有数值：武器每级属性、进化、被动、敌人、角色、经验曲线、局外强化 |
| `src/game/director.ts` | 刷怪节奏、脚本事件（包围、蜂群、首领）、敌人随时间成长 |
| `src/game/weapons.ts` | 8 种武器及其进化形态的行为 |
| `src/game/achievements.ts` | 成就定义、判定、终身统计 |
| `src/scenes/GameScene.ts` | 核心循环：玩家、敌人 AI、首领、掉落、伤害、特效 |
| `src/scenes/UIScene.ts` | HUD、升级选卡、暂停、结算、成就提示、触屏摇杆 |
| `src/scenes/MenuScene.ts` | 主菜单、角色选择、成就、局外强化商店 |
| `src/game/textures.ts` | 运行时用 Canvas 绘制全部贴图（无美术资源文件） |
| `src/game/audio.ts` | WebAudio 实时合成音效（无音频文件） |
| `src/game/music.ts` | 实时合成的背景音乐，随战况分 4 层强度 |

调平衡主要改 `data.ts` 和 `director.ts`。
